# Jyut OCR 詳細版面規則

呢份 reference 講版面同文類判斷：長會議報告、合訂講義、章程、表格、票據、印章同尾頁。用嘅人係睇圖嘅校對者：A 套答 packet 題嘅 agent（照題目問嘅位睇圖）、人手轉錄嘅 writer（`structured-workflow.md`），同對住 `doubts.md` 核書嘅用戶。B 套（本機模型校對）嘅 agent 喺對話入面唔讀頁圖：呢度講嘅核圖由流程問模型，定唔到嘅寫入 `doubts.md` 交用戶。反覆近形錯字另讀 `common-ocr-traps.md`。

當前 repo 有 `AGENTS.md` 或其他本地指示時，先跟本地規則。

## 輸出格式（評測規則）

- 內容：成頁轉錄：正文、標題、數字、標點、圖表入面嘅字、表外說明、註釋，同頁頭頁尾未完嘅句。只刪書眉、頁碼、版心／書口、印章、索書號、條碼同館藏印；正文數字、註號、表內標題唔係家具。
- 字：照原圖用字、字形、標點同閱讀次序，唔翻譯、唔改正、唔補圖以外嘅字。直排由右至左逐欄、欄內由上至下讀。印出嘅星號寫 `\*`；雙圈句號寫「。。」（`U+16FE6` 一律寫成「。。」），唔改成一個句號。
- 空格（全形 `U+3000` 對半形 `U+0020`，按語境區分）：
  - **用全形空格 `　`（`U+3000`）**：（1）舊式無圈點或少圈點文獻喺句逗停頓處空出一整格漢字位（空格斷句，同一處停頓連續多格留白仍寫一個 `　`）；（2）中文並列詞項、名錄人名、日期同出處、中文題號同題名之間印出嘅單格空位（如 `甲乙　丙丁`、`一　凡例`），以及公文奏摺行內單格挪抬留白。普通字距唔寫空格；普通段落首行縮進改用 Markdown 空行分段表示，行首同行尾唔留 `　`（無項目符號嘅目錄附項按原印低一兩格縮排除外）。
  - **用半形空格 ` `（`U+0020`）**：（1）Markdown 區塊語法分隔符（`# `、`## `、`- `、`1. `、`> `——注意 `##　` 用全形空格會令 CommonMark 認唔到標題）；（2）西文單詞、縮寫同姓名縮寫之間（如 `G. P.`、`No. 12`）、西文標點後嘅西文間距、阿拉伯數字同西文單位之間（如 `150 dpi`）；（3）HTML 標籤與屬性內部（如 `<td rowspan="2">`）。
- 註：引用 `[^n]` 留喺原位，定義 `[^n]: …`；標號全書唯一，同一原印號再用就改 `[^n-2]` 呢類 ID；得引用或者得定義就留嗰一半。
- 表：見下面〈表格、表單、圖同空白頁〉。
- 交付稿唔自己加頁碼分隔、模型解說、YAML 或者外層 code fence；page marker 淨係工作稿用。

## 書目 metadata 同 heading

- 校對既有 Markdown 時，開頭若有 `---` metadata block，要原樣保留喺最前面；唔當正文 heading 或頁面雜訊。
- 先界定交付範圍係全掃描本定正文-only。全書識別通常保留只出現一次嘅扉頁、英文題名、版權／CIP、凡例、贊助題記、照片圖說同來源說明；呢啲唔係重複頁面家具。
- 只有 PDF、既有 OCR 或可靠同版書目清楚提供題名、編者、版本、藏本、影印／編審／校對資料時，先補 metadata。
- 全書題名用 `#`；主要議案、報告、呈文、課目或大篇用 `##`；其下章節、`呈文`、`議草`、`批答`、`請議書`、`箚覆` 等按父子關係使用 `###` 以下層級。
- heading 唔只靠短句判斷，要同時睇 PDF 字級、位置、留白、欄位同前後結構。`至……今照修正……` 呢類承接句通常仍係正文。
- 目錄完結後若隨即接正文題名，要結束 list，再另起相應 heading。
- 同頁可能交錯多份短文件；頁頂短句可能係新案，唔一定係上一段續文。反過來，課目突然轉換即使上一頁半句未完，亦要按 PDF 頁序保留，唔好自行補橋接文。
- 疑似題名黐正文時，只有字級、位置、留白同篇章關係支持先拆 heading；套語重複唔係充分證據，亦唔好順手統一異體字形。

## 段落同跨頁閱讀次序

- 校對後一個語義段落寫成一個 Markdown 段落，唔保留 OCR 原始行寬、直排行、換欄或 page boundary 軟換行。
- 先核對閱讀次序、縮排、留白同鄰行。語法未完只係軟換行線索，唔係合併指令；原書真換段、抬頭、轉篇或半句要保留。
- **空格斷句書嘅欄頂留白同換段判別**：直排空格斷句書入面，如果前一欄最底一格尚未到底已有大片留白、下一欄欄頂又低一至兩格起行，通常係**換段**（寫成空行分段，新段行首唔留 `　`）；反之，如果前一欄最底一格剛好寫滿字，而下一欄欄頂只空出一格漢字位承接上句語氣，嗰格留白其實係跨欄嘅**句讀空格**（唔換段，兩欄接續處寫一個全形 `　`）。
- 唔好只因兩行都長就合併；OCR 特別短行可能對應真正新段、短標題、批答、署名或敬語抬頭。
- 奏摺、呈文、請願書入面 `伏候`、`呈請`、`奉`、`欽奉` 後面可能因抬頭另起 `督部堂`、`旨`、`上諭`、`皇上`。要同時睇版面同語氣，唔可以機械黐行或斷段。
- 頁尾接頁首時以閱讀次序為準；欄尾、頁尾、註腳位置同 marker 本身都唔自動代表新段。
- 頁底註腳插入未完正文時：先接完整正文；嗰頁嘅註定義放喺接好嗰段之後，按原印次序；冇跨頁接續就留喺頁底（腳本流程見 `long-book-workflow.md`〈註腳〉，人手轉錄見 `structured-workflow.md`）。
- PDF 最後正文頁若本身停喺半句，而下一頁係空白或另一篇，忠實保留半句並報告，唔好憑上下文補完。

## 清單、章程同官文

- 簡單平行嘅目錄、條文、問題、證據、辦法同枚舉可用 tight bullet list；保留原項號，例如 `一`、`二`、`第一條`、`甲一`，唔好轉成現代編號。
- 簡單連續 items 中間唔加空行；若同一 item 包含多段、引文或其他 block，要保留來源層次同適當縮排，唔為 tight-list 檢查壓平。現有 auditor 以 tight lists 為主；遇到未支援嘅合法結構，記錄具體限制同未通過項目，唔聲稱 clean。跨頁真 break 仍用既有 boundary contract，唔自行加寬例外。
- 跨 OCR 行或跨頁嘅同一 item 續文縮入該 item；新 item 另起 bullet。縮入行以 `一……`、`甲……`、`乙……` 開頭時，必須對 PDF 判斷係新項定續文。
- 長章程要核對條號連續性。`附說`、解釋同跨頁續文按 PDF 歸入原條，唔好誤開新條。
- OCR 可能漏 item 前嘅 `-`，亦可能將正文中一個字誤造成 bullet marker；若 list 結構令語意突然斷裂，要回到頁圖。
- 來源句、承接句、治本／治標辦法前後嘅說明通常係普通段落，唔因為鄰近清單就一併變成 item。

## 頁面家具

- 移除書眉、頁碼、版心／書口、書脊同卷冊邊欄，以及印章、索書號、條碼同館藏印；OCR 工具標題同空白頁 notice 亦唔係來源正文。唔按「承印／叢書／來源」等標籤或頁底位置直接刪字。
- 大型叢書同長報告嘅家具會有大量 OCR 變體；搜尋題名、局名、叢書名同承印片段只係提示，唔可以用全域替換盲刪。
- 課名、堂名、書名或官署名如果落喺正文句內，要保留。疑似家具同正文黐住時，人手轉錄先 render 對位；腳本流程嘅 agent 唔另外開圖（A 套淨係睇題目畀嘅圖）。
- 封面題名可轉成 `#`。一次性承印、出版、版本同來源資料照轉；印章同館藏印唔轉；手寫註記等後加標記同印刷正文分開記錄，是否轉錄按已定交付範圍處理。
- 頁底獨立報紙來源、日期、編者題解或檔案來源可能係正文 apparatus；唔好只因位置似頁腳就刪。

## 表格、表單、圖同空白頁

- 先核對表格框線、欄列、空格同閱讀次序。表一律整理成橫向閱讀：橫排表保持原行列；直排表將原圖由右至左嘅直欄依次變成由上至下嘅行，欄內由上至下嘅格變成由左至右嘅欄，合併格嘅 `rowspan`／`colspan` 對調；唔按內容自行重排行列。有表頭嘅簡單表用矩形 Markdown 表；冇表頭或者有合併格用閉合嘅 HTML `<table>`（`<tr>`、`<td>`／`<th>`，需要先用 `rowspan`／`colspan`），唔虛構表頭，唔拆格重複填值或猜補缺格。表名、表前後文字同表註保留。
- 金額、人數、地名、罰欵、捐項、投票、列席／缺席清單經常係分欄表格；數字開頭嘅續行未必係新條。
- 表格完成後另算欄數、列數、小計同總數；數值吻合唔代替逐格核圖，亦唔為湊合計改原數。Bundled table audit 只檢查 Markdown pipe table 欄數，唔驗 HTML 合併格；HTML 要另外核對每格內容、跨格關係同渲染結果，唔將腳本無報錯當已驗證。
- 既有 `table-cont` boundary contract 只接受兩邊都係 pipe rows；HTML 跨頁唔可以直接套用。保留正確表格結構同頁面來源，交代未支援嘅 contract／未通過 gate，唔用 `join` 或其他假 label 冒充已驗證。
- 跨頁續表合併成一張完整表，保留各頁全部格內同表外內容：頁頂重印相同表頭（直排右至左嘅欄名逐格倒讀相同都算）就只保留一次；欄名、次序或分組有任何變化就唔可以機械去重。腳本流程嘅接表規則見 `long-book-workflow.md`〈跨頁表格〉。Final audit 要逐行檢查 unescaped pipe／欄數一致。
- table cell 需要保留多行時可以用 `<br>`；拉丁掃描命中 `br` 屬有意格式，但仍要確認無其他雜訊。
- 表單、票據、圖表、地圖同圖說入面印咗嘅字照轉寫；預設唔抽圖（腳本流程要用戶要求先加 `--extract-figures`，見 `long-book-workflow.md`〈圖：淨係留圖片（--extract-figures）〉）。只有 table 更忠實時先做 table；模糊格位唔好默默推斷。
- 另一題名或附錄未確認屬本書前，唔好硬併。
- **淨係人手轉錄（`structured-workflow.md`）或者用戶覆核嗰陣**，先另外開圖核：兩個引擎都漏咗嘅格由原圖補核；OCR 判空白嘅頁 render 放大，檢查淡字、規則、印章、表格、圖同尾頁小字；尾頁有反白、修補塊、遮字或淡墨，可以比較普通圖、反色圖同局部 crop。腳本流程嘅 agent 唔做呢啲：A 套淨係睇 packet 題目問嘅位，同 `SKILL.md` 四.1 嘅空白候選全頁睇一眼；B 套唔睇圖。定唔到嘅由流程寫入 `doubts.md`。

## 文類專項

- 速記錄以發言人轉換作強分段訊號，例如 `某號議員謂`、`督部堂代表謂`、`議長謂`。若上一短行只係發言人標籤，下一行係同一人內容，應按版面合成同一段。
- 講義本身可能有 `。`、`。。`、`、` 等舊式標點，必須逐頁保留；唔好因其他無標點書種而批量刪除或正規化。
- 法律、政治、經濟講義可有真實歐文詞源。`[A-Za-z]` 命中係候選檢查，唔係自動雜訊。
- 官文敬語抬頭同直排換欄只係版面信號；最後分段仍要兼顧句法同 PDF 留白。
- 多課合訂講義可用 `##` 表示主要課目，課內章、節、欵逐級下降；唔好因全書合訂就將所有題名壓成同一層。

## 逐頁 final pass

人手轉錄（`structured-workflow.md`）或者用戶覆核嗰陣，逐頁重看 assembled Markdown 同 PDF；腳本流程嘅 agent 唔做呢一步。每頁至少核對：

- 有冇漏段、多收家具、重複頁、錯序、spread／rotation 誤讀或尾頁漏 render；
- 低信心括號同語境不通嘅高信心字；
- 標點嘅漏／增／形位、外文、數字同註號；兩份底稿一致或讀得通亦唔略過；
- heading 層級、真正新段、跨頁 join、list item 邊界、table 同註腳閱讀次序；
- 人名、官職、地名、日期、金額、項號同可重算結構不變量；
- 已校同未校範圍有冇混淆。

刪 marker 後再跑適用嘅 bundled audit scripts，逐項人工處理輸出；按已選 profile、實際風險同用戶要求安排獨立覆核。多 agent、已安排嘅 independent review 同 late-patch 重核仍跟 `subagent-orchestration.md`，唔因簡化規則而免除。完成聲明要按主 skill 列明逐頁視覺範圍、缺重頁、外部復原、疑難同驗證結果；裁決解釋留喺 review 記錄，唔混入來源正文。
